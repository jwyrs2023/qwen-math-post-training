# 实验五 · 标准 GRPO 的训练步数与收益曲线

本页记录实验前冻结的设计。已完成的训练与评估见[五轮实验报告](../reports/实验一至五阶段汇总.md)。

## 研究问题

第四轮单种子 GSM8K 验证曲线在 160、320、640 步分别为 74.8%、77.2%、77.6%。第五轮估计三个量：最早达到实用增益的步数，增加更新的边际收益，以及首次出现持续平台期的步数范围。分别报告 GSM8K 和 SVAMP。平台期指本配置、题集和预算下的准确率变化，不能视为训练目标或模型全局收敛。

## 对照设置

- 仅运行标准 GRPO。沿用第四轮的 Qwen2.5-1.5B、冻结 SFT、LoRA、审计训练题池、均匀有放回采样、正确率奖励、每题 4 个回答、每更新 4 个题组、学习率恒定 5e-6、温度 0.8、top_p 1.0、KL 系数 0.02。复核有效配置、依赖版本、模型和题单哈希。
- 每个种子（42、43、44）各跑一条从冻结 SFT 起步的连续轨迹。事先固定每条轨迹的完整抽题序列，沿用恒定学习率，固定生成与评估协议。横轴为优化器更新步数。累计不同训练题数、训练生成 token 和 GPU 时间作为辅助横轴。延长训练会同时增加采样与数据曝光，结论适用于该标准 GRPO 配置。
- 保留评估用 adapter 和可恢复训练状态。第四轮的 save_only_model=True 仅保存模型，不能从 640 步 adapter 恢复原轨迹。第五轮训练需保存优化器、调度器、Trainer 与随机数状态，并记录数据游标。在短跑中对照连续运行和断点恢复，核对接下来的题组、奖励日志及参数轨迹。恢复验收前不依赖分段续训。

## 检查点与评估

| 阶段 | 检查点（优化器更新步） | 数据 |
|---|---|---|
| 起点 | 0 | 每个题集各评估一次冻结 SFT，三个种子共享 |
| 第一阶段 | 80、160、240、320、480、640、960、1280 | GSM8K 每点。SVAMP 评估 160、320、640、960、1280 |
| 第二阶段 | 1600、1920、2240、2560 | 两个题集均评估；根据下述预定规则决定是否继续 |

GSM8K 使用原 500 道验证题，SVAMP 使用原 854 道题。二者均已在第四轮看过，在第五轮作为固定曲线评估集。固定 greedy、FP32、最大 512 新 token 和严格数值解析，逐题预测与检查点哈希入档。如需对所选步数做独立确认，须在启动前另冻结一份未使用且与所有训练和既有评估数据去重的题集，并锁定步数后一次性评估冻结 SFT 和所选检查点。若缺少合适的新题集，只报告两条曲线的结论。

## 预设判定

下列阈值已写入本地冻结协议。

1. **开始见效**。某检查点三种子平均相对 SFT 提升至少 1 个百分点，且配对区间下界高于零。报告最早达标的已测步数及前一已测点。两个题集分别判定。
2. **边际收益与平台期**。从 640 步起，以 320 步为一个区间。两个连续区间的三种子平均准确率变化，其按题配对置信区间都落在 −1 至 +1 个百分点内，才称达到该题集的实用平台期。两个题集均达到才停止继续增加步数。例：640→960、960→1280 均满足，才能在 1280 步确认自 640 步起的两个区间进入平台。
3. **预算硬上限 2560 步/种子**。在三个种子均到达阶段检查点并完成评估后，按既定判据继续。区间较宽时记为证据不足；仍上升、回落或出现种子分歧时分别报告。达到硬上限仍未确认平台，就报告已测上限与最后区间，不能强行给出收敛点。
4. **区间与多次查看**。同一题目上先求各固定种子的差值，再对题目做配对 bootstrap。主图画逐种子曲线与三种子平均；附图画相邻检查点差值。报告名义 95% 区间供读图，正式判定对预定检查点和两题集的比较族作同时区间校正。区间以三个固定种子为条件，同时单列每个种子的结果。使用第四轮逐题差值做了历史精度核算，结果与范围见下文。

## 产出与资源

产出两条准确率及增益曲线、320 步边际增益图、分种子逐题预测、累计 token 与时长，以及带不确定性的阈值结论。记录零方差奖励组比例、截断率、输出长度和 KL，作为理解曲线变化的辅助信息。

按第四轮标准 GRPO 实测约 11.2 秒/步，第一阶段三个种子训练约 12 GPU 小时，跑满约 24 GPU 小时。逐题评估也计费。按第四轮 GSM8K 约 13 条/分钟、SVAMP 约 26–37 条/分钟粗估，第一阶段训练及评估约 34–37 小时，跑满约 59–64 小时。若仍为 ¥2.04/小时，分别约 ¥69–76 和 ¥120–131，另计准备、空闲、归档和独立确认。批量评估只有在逐题判分一致性和生成差异验收后才用于正式曲线；以实测速度重算预算。

## 本地实现与上机入口

机器可读协议位于 `reports/protocol.json`。每个阶段在三个种子均到达同一步数后运行两条曲线的评估和统计。第一阶段到 1280 步，随后以 320 步为单位逐次判断，正式停止要求两个题集在当前终点对应的同一对连续区间都满足等效判据。报告同时列出点估计看似平坦但区间过宽的区间，区分趋势和已确认的平台期。
